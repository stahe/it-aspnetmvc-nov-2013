# Introduzione ad ASP.NET MVC attraverso esempi (novembre 2013)

Questo repository contiene la versione **HTML** del documento *Introduzione ad ASP.NET MVC attraverso esempi*, pubblicato originariamente nel **novembre 2013**. 

L'obiettivo è quello di introdurre, attraverso esempi, i concetti chiave di **ASP.NET MVC**, un framework web .NET basato sul modello **MVC (Model – View – Controller)**. 

## Leggi il documento online

* Sito web del documento: [https://stahe.github.io/it-aspnetmvc-nov-2013/](https://stahe.github.io/it-aspnetmvc-nov-2013/)
## Prerequisiti

Per comprendere gli esempi sono richiesti pochi prerequisiti; è sufficiente una **conoscenza di base di C#**.
